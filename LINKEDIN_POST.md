I read 8,473 job postings.

The #1 skill for Data Analysts isn't Python.

It's SQL: asked in 67% of postings, about 10x more often than in the other two roles.

I'm an Industrial Engineering & Management student, and 3 jobs come up in every career conversation on campus: Product Manager, Project Manager and Data Analyst.

So I stopped guessing what to learn and counted.

Top 3 skills per role:

📊 Data Analyst
1. SQL (67%)

2. Backlog / Prioritization (65%)

🗂️ Project Manager

The plot twist:
Communication is in 69-85% of postings in EVERY role.
Everyone expects it, so it won't set you apart. The hard skills will.
